# בקשה להיתר — MVP

משחק לשיתוף ציבור בתהליך הוצאת היתר בנייה, בהשראת "החבילה הגיעה" של אפרים קישון.
התושב עובר את הדרך מהחלום להיתר, תחנה אחר תחנה, ולומד להבחין בין **חובה**, **צריך** ו**רוצים**.

## הרצה
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 18 בדיקות מנוע ותוכן
npm run build    # בילד סטטי לתיקיית dist
```
נדרש Node 18 ומעלה.

## מה יש ב-MVP
- **ארבעה מסלולים:** תוספת בנייה, בית פרטי, בניין, תוספת ממ"ד. שני מגרשים לדוגמה לכל מסלול.
- **תחנות עיצוב לפי ההנחיות המרחביות של אשדוד (מהדורה 18):** גדר לרחוב, חומרי גמר, תוכנית צל, חזית פעילה, הצללה, גינה משותפת, תברואה, ניקוז.
- **הערות אדריכלית העיר** (נספחים א' ו-ב') אחרי תוכנית עיצוב ובינוי.
- **בדיקה מהירה "צריך היתר?":** 14 עבודות נפוצות — פטור, פטור עם דיווח, או היתר.
- **חמש דרכים:** תואם תוכנית, גמישות, הקלה מהרשימה הסגורה, בניין ותיק (תיקון 160), מורשה להיתר.
- **שער כשירות למורשה להיתר** עם חמש בדיקות והסבר לכל כישלון.
- **תוכנית עיצוב ובינוי** נכנסת רק כשהתב"ע של המגרש דורשת.
- **שולחנות גורמים** לפי תיק המידע: כבישים, נטיעות, נכסים, ניקוז, תאגיד המים.
- **שעון נסח טאבו:** תוקף 6 חודשים. עיכוב מחייב חידוש.
- **ארבע חפיסות:** אירוע, ידע, שכונה, אחריות (במסלול מורשה).
- **1–4 שחקנים** על אותו מכשיר, שמירה אוטומטית, מילון מונחים, מסך מקורות.
- **ניקוד:** היתר + מדד עיר + אמון שכנים + זמן + תקציב. היתר טוב הוא לא רק היתר מהיר.

## תוויות התוכן
לכל פריט יש אחת משתי תוויות:
- **לפי מקור** — מבוסס על מקור, והמקור מצוין לצדו.
- **חוק משחק** — כלל שנקבע לצורך המשחק, במקום שבו הדין אינו ודאי או שהמצב מובא להמחשה.

המשחק מלמד עקרונות. לפני בנייה בודקים את תיק המידע של המגרש. אינו ייעוץ משפטי.
